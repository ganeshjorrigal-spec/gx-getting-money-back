# Experiment Card

```yaml
experiment:
  decision_it_informs:
  hypothesis:
  causal_mechanism:
  riskiest_assumption:
  rival_hypothesis:
  predicted_observable_result:
  smallest_credible_test:
  participants_or_context:
  metric_and_measurement:
  support_threshold:
  falsification_condition:
  confounds_and_alternative_explanations: []
  kill_rule:
  revise_rule:
  scale_rule:
  owner:
  timing:
  ethical_or_reputational_checks: []
```

A test that cannot change a decision is not a useful experiment.

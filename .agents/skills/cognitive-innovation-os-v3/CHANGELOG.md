# Changelog

## V3.0.0 — Initial Cognitive Innovation OS build

- Preserved Cognitive Stack V2 intact under `engine/cognitive-stack-v2/`.
- Reframed the system from answer generation to outcome-oriented work orchestration.
- Added QUICK, DEEP, LOOP, and AUDIT modes.
- Added mission contract, work-intention/maturity routing, and evidence gate.
- Added seven explicit work loops with stopping conditions and state updates.
- Added five domain packs for consulting, product, marketing, campaigns, and consumer behavior.
- Added six independent evaluators.
- Added decision, innovation, experiment, final-brief, project-state, and learning templates.
- Added benchmark, ablation, and regression testing protocols.

# Example — Consulting Diagnosis Loop

## Mandate

A client asks for a sales-force productivity program because revenue per salesperson has declined.

## V3 route

1. Separate the observed metric from the proposed cause.
2. Generate rival hypotheses: lead quality, territory potential, product availability, pricing, incentive gaming, manager span, sales capability.
3. Map evidence predicted by each cause.
4. Run the cheapest discriminating analyses/interviews.
5. Reject generic training if capability is not the binding mechanism.
6. Develop strategic alternatives linked to surviving causes.
7. Specify implementation, owners, leading indicators, and review rules.

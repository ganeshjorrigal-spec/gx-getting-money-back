# Evaluator — Novelty

Judge mechanism novelty separately from surface novelty.

## Tests

- Does the option change the causal mechanism or only the expression?
- Is it merely a familiar pattern imported without adaptation?
- Does it challenge a category assumption?
- Is the combination non-obvious and coherent?
- Would a competitor generate the same idea from the same brief?
- Is the novelty legible enough to be understood and adopted?

## Rating

- 5 — new mechanism/category logic with clear relevance.
- 4 — uncommon recombination that changes behavior/system dynamics.
- 3 — meaningfully differentiated execution of a known mechanism.
- 2 — cosmetic or channel-level variation.
- 1 — generic convention.

Novelty below 3 cannot be called an innovation, though it may still be an effective optimization.

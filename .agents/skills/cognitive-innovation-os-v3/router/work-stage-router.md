# Work-Stage Router

Route on two axes before using the Cognitive Stack.

## Work intention

| Intention | Required transformation |
|---|---|
| DISCOVER | Unknown opportunity → opportunity map |
| EXPLAIN | Confusion → causal/structural understanding |
| DIAGNOSE | Symptom → competing causes and discriminating evidence |
| FORECAST | Uncertainty → scenarios, probabilities, indicators |
| DECIDE | Options → chosen/staged/tested disposition |
| INVENT | Need/constraint → mechanism-distinct possibilities |
| DESIGN | Chosen direction → coherent system or artifact |
| VALIDATE | Claim/concept → evidence and decision rule |
| PERSUADE | Position → audience-specific belief/action pathway |
| IMPLEMENT | Recommendation → owners, sequence, dependencies, metrics |
| LEARN | Result → updated model and rules |
| INSTITUTIONALIZE | Repeated success → reusable process, governance, memory |

## Maturity

| Maturity | Main need |
|---|---|
| UNFRAMED | Define outcome and problem boundary |
| FRAMED | Identify evidence and rival hypotheses |
| RESEARCHED | Synthesize and locate decision-relevant uncertainty |
| OPTIONS_READY | Evaluate mechanisms and trade-offs |
| SELECTED | Design test or implementation |
| TESTING | Interpret results and decide kill/revise/scale |
| IMPLEMENTING | Remove bottlenecks and monitor leading indicators |
| REVIEWING | Capture learning and change the operating rule |

# Mode Router

Choose the lightest mode capable of producing a reliable outcome.

## QUICK

Use when the question is consequential enough for one deliberate pass but does not require research, competing workstreams, or iterative feedback.

Minimum sequence: mission → evidence labels → cognitive route → recommendation → next action.

## DEEP

Use when the work involves strategy, diagnosis, innovation, product direction, campaign planning, stakeholder persuasion, or an important decision.

Sequence: full mission contract → evidence gate → cognitive route → domain pack → alternatives → evaluator passes → disposition → work brief.

## LOOP

Use when progress depends on new evidence, prototype results, stakeholder feedback, repeated refinement, execution signals, or a future outcome.

Requires project state, one primary loop, iteration budget, evaluator, and stopping conditions.

## AUDIT

Use to review a prior answer, plan, recommendation, campaign, product, decision, or skill behavior.

AUDIT may expose:

- baseline answer versus V3 result;
- selected and rejected models;
- worldview and rival worldview;
- evidence defects;
- unsupported leaps;
- evaluator disagreements;
- whether each cognitive step earned its place.

## Selection rule

Choose LOOP only when another cycle can receive new information or materially transform the artifact. Repeating the same prompt without new evidence, a new critic, or a changed constraint is not a loop.

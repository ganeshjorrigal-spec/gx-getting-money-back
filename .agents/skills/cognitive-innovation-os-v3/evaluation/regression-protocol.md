# Regression Protocol

After modifying the skill:

1. Run all benchmark cases or a representative subset.
2. Check that the original Cognitive Stack files remain intact.
3. Verify mode selection is proportionate.
4. Verify no idea generation occurs before the evidence gate in DEEP/LOOP mode.
5. Verify at least three mechanism-distinct options in innovation tasks.
6. Verify evaluator disagreement is preserved.
7. Verify every loop has state change and stopping logic.
8. Verify final output is one decision-ready brief unless AUDIT mode is requested.
9. Verify cognitive-signature claims are restrained and evidence-labelled.
10. Compare scores against the previous version and inspect any decline of 0.5 or more.

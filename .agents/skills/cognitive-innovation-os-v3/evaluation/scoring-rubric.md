# V3 Scoring Rubric

Score 1–5.

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| Mission clarity | vague | usable | decision-owner and acceptance criteria explicit |
| Evidence integrity | unsupported | assumptions visible | critical claims grounded and uncertainty actionable |
| Reframing value | restates prompt | useful refinement | changes the decision space |
| Cognitive contribution | decorative models | some insight | selected moves materially alter action |
| Option diversity | cosmetic variants | some mechanism difference | genuinely distinct causal mechanisms |
| Adversarial robustness | no dissent | objections listed | rival worldview changes design/decision |
| Domain usefulness | generic advice | domain-shaped | ready-to-use native work product |
| Testability | unverifiable | test suggested | discriminating test with thresholds and rules |
| Feasibility | aspirational | plausible | constraints, dependencies, owners, timing clear |
| Outcome orientation | answer only | next step | decision/test/implementation and learning loop |

## Passing standard

- No dimension below 3.
- Evidence integrity, domain usefulness, and outcome orientation must be at least 4.
- For innovation work, option diversity and testability must be at least 4.

# Domain Pack — Management Consulting

## Primary transformation

Ambiguous client mandate → evidence-based diagnosis → strategic alternatives → decision → implementation architecture.

## Required workstreams

1. **Mandate and stakeholder system** — decision owner, sponsors, blockers, affected groups.
2. **Problem decomposition** — issue tree or system map without pretending the tree is the truth.
3. **Rival hypotheses** — multiple causal explanations with discriminating evidence.
4. **Evidence plan** — what must be learned from data, interviews, observation, benchmarks, or experiments.
5. **Strategic alternatives** — distinct mechanisms and trade-offs.
6. **Recommendation** — why this direction, why now, why not the alternatives.
7. **Implementation** — owners, decisions, capabilities, dependencies, incentives, metrics, risks.

## Useful preserved recipes

Wrong-Problem Detector; Differential Diagnoser; Root Cause Excavator; Complexity Reducer; Scenario Planner; Outside-View Estimator; Leverage Point Finder; Implementation Stress Test; Stakeholder Mapper; Resistance Diagnoser.

## Deliverable

### Executive decision brief

- mandate and decision;
- key finding and evidence;
- rival explanations considered;
- strategic alternatives;
- recommendation and economics/logic;
- risks and disconfirming signals;
- 30/60/90-day implementation architecture;
- unresolved decisions requiring client ownership.

## Consulting failure checks

- analysis reproduces the client's initial framing;
- recommendation is a generic best-practice list;
- interview claims are treated as facts;
- implementation is detached from incentives and decision rights;
- the deck is complete but the decision remains unclear.

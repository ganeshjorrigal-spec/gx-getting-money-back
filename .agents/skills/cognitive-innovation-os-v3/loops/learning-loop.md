# Learning Loop

**Use when:** A decision, experiment, launch, engagement, campaign, or intervention has produced results.

## Cycle

1. Retrieve the original prediction and assumptions.
2. Compare predicted and observed results.
3. Identify surprise, calibration error, and causal ambiguity.
4. Separate execution failure from theory failure.
5. Identify which model or recipe helped and which added no value.
6. Update the rule, playbook, threshold, or domain pack.
7. Define the next application that would test whether the lesson transfers.

## Stop when

- a specific operating rule has changed;
- the result is too ambiguous for a reliable lesson;
- additional analysis would be hindsight storytelling.

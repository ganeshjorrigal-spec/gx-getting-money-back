# Decision Loop

**Use when:** There are real alternatives and the cost of delay or error matters.

## Cycle

1. Define decision, owner, deadline, reversibility, and stakes.
2. Expand the option set if the choice is artificially binary.
3. Establish decision criteria before scoring options.
4. Use base rates, rival worldview, and downside analysis.
5. Identify critical assumptions for each option.
6. Calculate the value of waiting or gathering information.
7. Choose COMMIT, STAGE, TEST, or PAUSE.
8. Predeclare review and exit conditions.

## Stop when

- an option dominates on non-negotiables;
- a staged bet captures most upside while limiting downside;
- more information costs more than it is expected to change the decision;
- the deadline requires a decision under acknowledged uncertainty.

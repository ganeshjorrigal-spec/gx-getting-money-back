# Execution Loop

**Use when:** The direction is known but delivery, coordination, throughput, or adoption is failing.

## Cycle

1. Define the next observable outcome.
2. Map work, decisions, dependencies, handoffs, delays, and incentives.
3. Locate the binding bottleneck.
4. Select one intervention at the bottleneck.
5. Assign owner, timing, leading indicator, and escalation rule.
6. Observe actual throughput and unintended effects.
7. Update the system map and repeat at the new bottleneck.

## Stop when

- the target operating level is sustained;
- the bottleneck moves outside the team's authority;
- the solution creates unacceptable second-order effects;
- implementation requires a strategic reframing.

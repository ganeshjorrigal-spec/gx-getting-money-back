# Diagnosis Loop

**Use when:** A symptom, performance gap, behavior, or system failure has multiple plausible causes.

## Cycle

1. Describe the symptom without causal language.
2. Generate competing causal hypotheses from different mechanisms.
3. Use Root Cause Excavator or Differential Diagnoser.
4. Map evidence expected under each hypothesis.
5. Find a discriminating observation or test.
6. Update confidence; eliminate or revise hypotheses.
7. Identify the intervention implied by the surviving mechanism.

## Stop when

- one causal account is sufficiently supported for a reversible intervention;
- two accounts require different high-value tests;
- evidence is insufficient and further diagnosis would be speculative.

## Output

Differential diagnosis table plus the next discriminating test or intervention.
